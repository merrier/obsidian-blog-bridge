## Style Prompt

中文版 Blog Bridge 产品宣传片延续 README 资产中的清爽产品视觉：明亮画布、精确的界面层次、温和网格、Obsidian 紫、GitHub 蓝与发布绿。整体应该像给写作者和技术型博主看的发布工具短片，强调“手动选择、Markdown 原样、GitHub 提交、静态站适配”，避免夸张的自动化承诺。

## Colors

- Canvas: `#F8FAFC`
- Text: `#182230`
- Muted text: `#59697B`
- Obsidian purple: `#7654D4`
- GitHub blue: `#2E86DE`
- Publish green: `#13A67B`
- Rule / chrome: `#D7E0EA`

## Typography

- Primary: `Noto Sans JP`, `Inter`, `ui-sans-serif`, `system-ui`, `sans-serif`
- 中文标题使用 800-850 字重，短句、强节奏；说明文字保持清晰，不堆功能点。

## What NOT to Do

- 不使用深色赛博或霓虹仪表盘风格。
- 不新增与 README 资产无关的品牌色。
- 不用重度模糊或氛围遮罩盖住产品界面。
- 不暗示自动监听、定时同步或自动部署；产品定位是手动同步。
