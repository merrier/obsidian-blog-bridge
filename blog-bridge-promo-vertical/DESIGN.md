## Style Prompt

Blog Bridge uses a clean Obsidian-adjacent editorial product style: bright canvas, crisp UI surfaces, gentle grid structure, and purposeful motion that feels like notes moving through a dependable publishing pipeline. The look should feel developer-friendly and writer-friendly at once, showing the bridge from local Markdown to GitHub-backed static blogs without turning into a generic neon SaaS reel.

## Colors

- Canvas: `#F8FAFC`
- Text: `#182230`
- Muted text: `#59697B`
- Obsidian purple: `#7654D4`
- GitHub blue: `#2E86DE`
- Publish green: `#13A67B`
- Rule / chrome: `#D7E0EA`

## Typography

- Primary: `Inter`, `ui-sans-serif`, `system-ui`, `-apple-system`, `BlinkMacSystemFont`, `Segoe UI`, `Arial`, `sans-serif`
- Use strong 800 weight display type for product claims, 500-600 for UI labels, and compact all-caps labels sparingly.

## What NOT to Do

- Do not use a dark cyberpunk or neon dashboard treatment.
- Do not invent unrelated brand colors beyond the README asset palette.
- Do not obscure the product UI screenshots with heavy blur or atmospheric overlays.
- Do not imply automatic publishing or scheduled sync; the product is intentionally manual.
