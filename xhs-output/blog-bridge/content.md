# Obsidian 用户的小痛点

很多人喜欢在 Obsidian 里写文章。

但真正发布到博客时，还要复制 Markdown、整理 frontmatter、处理图片路径，再提交到 GitHub。

每一步都不复杂，但很打断写作节奏。

---

# Blog Bridge 做什么？

Blog Bridge 是一个 Obsidian 插件。

它可以把选中的 Markdown 笔记，同步到 GitHub 托管的静态博客仓库。

支持 Hexo、Hugo、Jekyll、Astro、VitePress、MkDocs 等文件型 Markdown 博客框架。

---

# 它省掉哪些步骤？

- 自动放到对应文章目录
- 保留并补齐 frontmatter
- 本地图片一起提交
- 图片链接改成博客可访问路径
- 支持直接 commit 或创建 PR
- 状态页里可以查看同步结果

---

# 适合谁？

如果你满足这几个条件：

- 用 Obsidian 写作
- 有自己的静态博客
- 博客内容托管在 GitHub
- 希望保留 Markdown 工作流
- 不想每次手动搬运文章和图片

这个插件会很顺手。

---

# 简单工作流

Obsidian 写文章

↓

Blog Bridge 手动同步

↓

GitHub 仓库更新

↓

静态博客部署

写作留在 Obsidian，发布交给工具处理。
